# cybermogger

Портфолио: https://cybermogger.github.io/

HTML / CSS / JavaScript, без сборки. GitHub Pages: main, / (root).

BALCON и CUTHEADS — независимые демоконцепты для портфолио. Победа TerraWatch AI и продажа Портала времени ЧГУ подтверждены автором. Диплом с закрытым ФИО сохранён в certificates/.

Фотопревью взяты из авторских демосайтов BALCON и CUTHEADS. Остальные графические обложки — визуальные интерпретации. Шрифт Manrope загружается из Google Fonts; предусмотрен системный запасной шрифт. Для настройки уменьшенного движения используется prefers-reduced-motion.
